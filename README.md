# Soccer-Tip ⚽

A responsive football hub for match updates, fixtures, leagues, club spotlights and football stories.

## Run locally
Open `index.html` in any modern browser.

## Prototype features
- Responsive dark stadium-inspired design
- Match centre with All / Live / Upcoming filters
- League shortcuts and fixture previews
- FC Barcelona spotlight
- Editorial cards and demo newsletter form

## Data status
Match scores, fixture dates and editorial stories are illustrative placeholders, not live data. A verified football-data API is required before presenting them as current.
